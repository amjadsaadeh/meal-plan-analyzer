**Module-level imports (safe — no circular risk):**
```python
import logging
import os
from celery import shared_task
from celery.exceptions import SoftTimeLimitExceeded
from django.conf import settings
from django.core.files.base import ContentFile
from django.contrib.staticfiles import finders
from django.utils import timezone
from datetime import timedelta

from meals.models import BackgroundJob

logger = logging.getLogger(__name__)
```

**Task decorator:**
```python
@shared_task(
    bind=True,
    soft_time_limit=300,   # raises SoftTimeLimitExceeded after 5 min
    time_limit=360,        # hard kill after 6 min
    name="meals.tasks.generate_pdf_task",
)
def generate_pdf_task(self, job_id: str, meal_plan_pk: int) -> None:
```

**Task body structure (inside try/except SoftTimeLimitExceeded / except Exception):**

1. Mark job RUNNING, progress=0:
   `BackgroundJob.objects.filter(pk=job_id).update(status=BackgroundJob.Status.RUNNING, progress=0)`

2. Import inside function body to avoid circular imports:
   `from meals.views import get_meal_plan_context, django_url_fetcher`
   `from meals.models import SiteSettings`

3. Load context: `context = get_meal_plan_context(meal_plan_pk)`

4. Set logo_path and minilogo_path on context:
   - If `site.logo` is set: `context["logo_path"] = f"file://{site.logo.path}"`
   - Else: use `finders.find("meals/img/logo.png")` for a file:// URL
   - Same pattern for `minilogo_path` with `site.minilogo`

5. Milestone 25%: `BackgroundJob.objects.filter(pk=job_id).update(progress=25)`

6. Render HTML string: `render_to_string("meals/mealplan_pdf.html.j2", context)`
   Import `render_to_string` from `django.template.loader` at module level (safe — no circular risk).

7. Create WeasyPrint HTML object:
   ```python
   html = weasyprint.HTML(
       string=html_string,
       base_url=settings.SITE_BASE_URL,
       url_fetcher=django_url_fetcher,
   )
   ```
   Import `weasyprint` at module level.

8. Milestone 60%: `BackgroundJob.objects.filter(pk=job_id).update(progress=60)`

9. Generate PDF bytes: `pdf_bytes = html.write_pdf()`

10. Milestone 90%: `BackgroundJob.objects.filter(pk=job_id).update(progress=90)`

11. Build filename: sanitize `context["plan"].name` to ASCII, replace spaces with hyphens, append `job_id[:8]` suffix and `.pdf` extension.

12. Save file and finalize:
    ```python
    job = BackgroundJob.objects.get(pk=job_id)
    job.result_file.save(filename, ContentFile(pdf_bytes), save=False)
    job.progress = 100
    job.status = BackgroundJob.Status.DONE
    job.save(update_fields=["result_file", "progress", "status", "updated_at"])
    ```
    CRITICAL: `save=False` prevents double-save. `update_fields` MUST include `"updated_at"` or the auto_now field will not update.

**SoftTimeLimitExceeded handler:**
```python
except SoftTimeLimitExceeded:
    logger.warning("generate_pdf_task soft time limit exceeded for job %s", job_id)
    BackgroundJob.objects.filter(pk=job_id).update(
        status=BackgroundJob.Status.FAILED,
        error_message="Task timed out (soft time limit exceeded).",
    )
```
Catch this BEFORE `except Exception` — do NOT re-raise (the timeout is expected).

**Generic exception handler:**
```python
except Exception as exc:
    logger.exception("generate_pdf_task failed for job %s", job_id)
    BackgroundJob.objects.filter(pk=job_id).update(
        status=BackgroundJob.Status.FAILED,
        error_message=str(exc)[:1000],
    )
    raise  # re-raise so Celery marks the task as FAILURE in its own state
```

**Anti-patterns to avoid (from research):**
- Do NOT import `get_meal_plan_context` or `django_url_fetcher` at module level — circular import risk
- Do NOT use `self.update_state()` — `CELERY_RESULT_BACKEND = None`; direct ORM update is the pattern
- Do NOT use `save=True` (the default) when calling `job.result_file.save()` — use `save=False`
- Do NOT omit `"updated_at"` from `update_fields` — auto_now only fires if included
- Do NOT use `get_object_or_404` anywhere in this file — Http404 makes no sense in a worker
